Sobre o projeto
Projeto acadêmico desenvolvido na disciplina de Projeto Multidisciplinar do curso de Análise e Desenvolvimento de Sistemas.
O objetivo é estudar o desenvolvimento de um sistema Back-end para gerenciamento de pedidos de uma rede de restaurantes.
Tecnologias utilizadas
Python
Visual Studio Code
Draw.io para modelagem dos diagramas
Funcionalidades implementadas
Exibição do cardápio
Identificação do cliente
Seleção de produtos
Verificação da disponibilidade do produto
Cálculo do valor total do pedido
Validação da quantidade solicitada
Verificação e atualização do estoque durante a execução
Exibição do resumo do pedido

Como executar
Instale o Python no computador.
Baixe o arquivo main.py deste repositório.
Abra o arquivo no Visual Studio Code.
Execute o programa pelo terminal com o comando:
python main.py
Informe o nome do cliente, o produto e a quantidade solicitada.
Testes realizados
Foram executados testes com pedidos válidos, produtos inexistentes e quantidades superiores ao estoque disponível.
Limitações e melhorias futuras
O projeto está em fase de protótipo. O estoque é armazenado temporariamente durante a execução e reinicia quando o programa é executado novamente.
Como evoluções futuras, estão previstos:
Banco de dados para persistência das informações
API para gerenciamento de pedidos
Controle de estoque por produto e unidade
Gerenciamento de múltiplas unidades do restaurante
Autenticação e segurança dos dados
